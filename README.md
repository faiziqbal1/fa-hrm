# FA HRM

A Next.js application repository currently at its initial scaffold stage.

## Current status

The default Next.js starter page is in place. HRM functionality has not yet been implemented in this public repository.

## Run locally

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Stack

- Next.js
- React
- TypeScript

This repository is not presented as a completed HRM product yet.
